# mycalc

MyCalc is a Java-based calculator, that allows users to perform calculations and store their results and the calculation itself. The users can store a title and a description to each saved calculation, so they can document, store and revisit a calculation previously made.

**About the application:**

This application follows a MVC (Model, View, Controller) Architecture, which means it is divided into 3 main layers:

**View:** The layer that stores the code and logic of what a user can see during the usage of the application.

**Controller:** The layer that stores the business logic and the flow of data that transits between View and Controller.

**Model:** The layer that that manages the communication with the Database.
